What It Does

Bind by Pressing

Select the cockpit function, then press the switch — the same way you bind a control inside DCS. Move the switch, the binding moves with it.

Auto-Detecting Encoders

Wire an EC11 to any two free pins and turn the knob. The board detects the pair and configures its own hardware-timed quadrature decoder — clean, jitter-free.

Real Cockpit Lights

LED outputs driven by live DCS-BIOS data — APU Ready, Master Caution, gear and flap indicators. Reflect the actual state of the aircraft, on any pin you choose.

Firmware Dimmer

Set an encoder as backlight dimmer and it drives a PWM pin in firmware. Panel lights up with the sim closed, app closed, PC idle.

Live Wiring Check

Press a control and watch the exact pin light up on screen, labelled with its function. A pin lit while you touch nothing is a short.

One-Click Self-Test

Flags duplicate pins and binding conflicts before you fly. Shorts, conflicts and duplicate pins surface on the bench, not in the cockpit.

Specifications

Component Details
Controller STM32H743VIT6 — Arm Cortex-M7, 400 MHz, bare-metal USBX (no RTOS)
Inputs 61 native + 16 via I/O expander = 77 total on 2.54 mm headers
Encoders Up to 25 EC11 quadrature — hardware-timer decoded, auto-detected
Sampling 1 ms — native inputs and encoders (1000 Hz)
Outputs DCS-BIOS driven LEDs and warning lights on any free pin
Backlight PWM dimmer in firmware — works with sim closed
USB Single USB-C — composite HID + CDC, no driver install
Config Storage 8 MB QSPI flash (W25Q64JV) — power-off persistent
Board Size 114 × 60 mm — four mounting holes, silkscreened headers
Host Software Windows configuration app — free, included, no account
Aircraft Support F/A-18C Hornet database included; all DCS modules via DCS-BIOS
